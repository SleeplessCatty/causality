# P1-08 局部图交互与信息查看设计

版本：V1.0
日期：2026-07-21
状态：开发完成，等待人工复核
所属路线图步骤：P1-08 局部图交互与信息查看
前置步骤：P1-07 已完成用户验收并提交

## 1. 目标

在 P1-07 局部因果图基础展示之上增加清晰、可预测的节点与关系选择、邻接高亮、键盘因果链导航、右侧详情检查器和节点临时拖动，使用户能够查看图中元素的已有业务详情并连续探索因果链。

P1-08 不改变局部图查询规模、筛选条件或 ELK 布局参数。节点扩展、筛选和扩展时的布局稳定性继续由 P1-09 实现。

## 2. 非目标

P1-08 不实现：

- 50 或 100 个关联节点扩展；
- 最低置信度和最低案例数筛选；
- 悬浮高亮或悬浮 Tooltip；
- 多选、框选或批量操作；
- 同时打开多个详情检查器；
- 节点固定图标、手动解除固定或坐标持久化；
- 把当前选中元素写入 URL 或本地存储；
- 在检查器内编辑事件、关系或案例；
- 在检查器内加载全部关系案例；
- 新增或修改后端 API、共享契约、数据库结构；
- 移动端或触摸端交互适配。

## 3. 已确认原则

- 图生成完成后默认没有选中节点或关系；
- 不实现任何悬浮显示；
- 点击节点或关系只改变当前选择，不自动打开检查器；
- 选择关系时高亮关系及两个端点；
- 选择节点时高亮节点、全部直接相邻关系及另一端节点；
- 未高亮元素不降低透明度；
- 方向键沿拓扑和画面空间执行“节点 → 关系 → 节点”导航；
- 空格独立打开或关闭右侧检查器；
- 改变选择项不改变检查器开关状态；
- 右侧检查器固定约 380px；
- 节点详情显示名称、说明、别名和关键词；
- 关系详情显示原因结果、置信度、说明、案例总数和最近 5 条案例；
- 所有节点均可拖动，并仅在当前图会话保持临时位置；
- 设置新中心事件时保留当前查询方向；
- 交互状态由页面、画布 Runtime 和独立检查器组件分工管理。

## 4. 页面结构

检查器关闭时沿用 P1-07 全宽画布：

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 局部因果图                              12 个节点 · 15 条关系       │
├─────────────────────────────────────────────────────────────────────┤
│ [中心事件] [上游|下游|双向] [－][52%][＋][适应画布]               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│                         因果图画布                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

检查器打开后，工作区切换为画布加固定右栏：

```text
┌──────────────────────────────────────────────┬──────────────────────┐
│                                              │ 节点详情          × │
│                 因果图画布                   │ 运输成本上升         │
│                                              │ 说明 / 别名 / 关键词 │
│                                              │ [设为中心事件]       │
└──────────────────────────────────────────────┴──────────────────────┘
```

规则：

- 检查器宽度固定约 `380px`，占用工作区宽度，不覆盖检查器下方的画布；
- 打开或关闭时只调用 Cytoscape `resize()`，不重新运行 ELK；
- 不因打开检查器自动适应全图，避免节点突然缩小；
- 当前选择被右栏挤出可见区域时，只平移到距画布边缘至少 32px 的可见位置；
- 关闭检查器后恢复画布宽度，保留 zoom、pan、当前选择和节点临时位置；
- 系统启用“减少动态效果”时取消栏宽、平移和内容切换动画。

## 5. 选择状态模型

页面只保存以下临时状态：

```ts
type GraphSelection =
  | { type: 'node'; id: string }
  | { type: 'relation'; id: string }
  | null;

interface GraphInteractionState {
  selection: GraphSelection;
  inspectorOpen: boolean;
}
```

`selection` 与 `inspectorOpen` 相互独立：

- 初次布局完成：`selection=null`、`inspectorOpen=false`；
- 点击或方向键移动：只更新 `selection`；
- 空格：只切换 `inspectorOpen`；
- 检查器打开时改变选择：保持打开并切换详情；
- 检查器关闭时改变选择：只更新图上高亮；
- 点击检查器关闭按钮：只关闭检查器，保留选择；
- 点击画布空白：清除选择，保持检查器开关不变；
- 检查器打开但没有选择：显示“请选择节点或关系”；
- `Esc`：清除选择并关闭检查器；
- 选择状态不写入 URL，刷新后默认无选择且检查器关闭。

切换方向、搜索新中心、设置新中心、取得新的图响应或重新布局时，清除选择、关闭检查器并清除所有临时节点位置。

## 6. 鼠标选择与高亮

P1-08 不监听节点或关系的 `mouseover`、`mouseout`，不提供悬浮样式和 Tooltip。

### 6.1 选择节点

点击节点后：

- 当前节点使用深绿色粗边框和清晰外圈；
- 所有直接入边和出边使用较轻的绿色加粗；
- 每条相邻关系的另一端节点使用较轻的绿色边框；
- 不递归高亮两跳或更多节点；
- 其他元素保持 P1-07 原始样式和透明度。

### 6.2 选择关系

点击关系后：

- 当前关系线、箭头和标签使用深绿色强调并增加线宽；
- 原因端与结果端节点使用较轻绿色边框；
- 不继续高亮端点的其他关系；
- 其他元素保持原始样式和透明度。

当前元素使用 `is-current` 类，邻接上下文使用 `is-context` 类。每次选择变更在一个 Cytoscape batch 中清除旧类并应用新类，避免中间闪烁。

关系保留可见细线，但通过透明 overlay 增加点击命中宽度。关系文字和线条都可触发同一选择事件。

## 7. 键盘选择与空间导航

交互画布改为一个可聚焦的 `application` 区域，保持单一 Tab 停靠点。图中最多 21 个总节点时，不为每个 Canvas 元素生成独立 DOM Tab 停靠点。

### 7.1 快捷键

- 方向键：改变当前选择；
- 空格：打开或关闭检查器；
- `Esc`：清除选择并关闭检查器；
- 快捷键只在画布拥有焦点时拦截；
- 搜索框、方向按钮、检查器链接和按钮继续使用浏览器默认键盘行为。

没有选择时首次按任一方向键，先选择中心节点，不直接跨越到关系。

### 7.2 节点到关系

当前选择是节点时，只把该节点的直接入边和出边作为候选关系。每条候选关系使用关系中点作为导航位置：

1. 计算当前节点中心到关系中点的向量；
2. 只保留与按键方向点积大于 0 的候选；
3. 优先选择与按键方向夹角最小的候选；
4. 夹角相同时选择距离更近的候选；
5. 仍相同时按关系 ID 升序选择。

### 7.3 关系到节点

当前选择是关系时，只把原因端与结果端节点作为候选。使用关系中点到两个节点中心的向量执行相同的方向、夹角、距离和 ID 排序。

没有符合当前方向的候选时保持原选择，不循环到无关元素。导航成功后应用与鼠标选择相同的高亮规则。

### 7.4 无障碍反馈

- 画布焦点显示明确外框；
- `aria-live` 区域在选择变化后播报一次；
- 节点播报“节点：事件名称”；
- 关系播报“关系：原因事件到结果事件，置信度 X%，Y 条案例”；
- 检查器打开后焦点仍留在画布，用户可继续沿因果链移动；
- 用户需要操作检查器按钮或链接时，通过 Tab 进入检查器；
- 从检查器关闭按钮关闭后，焦点返回画布。

## 8. 右侧检查器

检查器共有五种内容状态：

1. 未选择提示；
2. 节点详情加载；
3. 节点详情；
4. 关系详情加载或详情；
5. 加载失败。

内容区独立滚动，页面标题、工具栏和画布不随长详情滚动。

### 8.1 节点详情

节点检查器调用现有 `GET /api/events/:eventId`，显示：

- “原子事件”类型标识；
- 标准名称；
- 事件说明，无说明时显示“未填写”；
- 全部别名，无别名时显示“未填写”；
- 全部关键词，无关键词时显示“未填写”；
- “设为中心事件”主操作。

不显示创建时间、更新时间或编辑入口。

选中当前中心节点时不显示可点击主操作，改为“当前中心事件”状态。点击“设为中心事件”后：

1. 保留当前 `upstream`、`downstream` 或 `both`；
2. 用所选节点 ID 更新 `centerEventId` URL 参数；
3. 关闭检查器并清除选择；
4. 清除全部临时节点位置；
5. 请求并布局新局部图。

### 8.2 关系详情

关系检查器调用现有 `GET /api/relations/:relationId`，显示：

- 原因事件名称、方向箭头、结果事件名称；
- 置信度；
- 案例总数；
- 关系说明，无说明时显示“未填写”；
- API 已返回的最近 5 条案例简短叙述；
- 案例超过 5 条时显示“查看全部 N 条”。

“查看全部”跳转到现有 `/cases?relationId=<relationId>`，由具体案例模块展示完整筛选结果。使用浏览器返回可以根据中心事件和方向 URL 恢复同一张图，但不恢复选中详情。

案例为零时显示“暂无具体案例”，不显示“查看全部”。P1-08 不在检查器内继续分页或请求全部案例。

### 8.3 加载、切换与错误

- 打开有选择项的检查器后立即显示稳定骨架；
- 检查器关闭时不主动请求详情；
- 检查器打开时改变选择，保留栏宽并在内容区切换骨架；
- TanStack Query 把 AbortSignal 传入现有详情 API；
- 快速切换选择时取消不再使用的请求；
- 已成功读取的详情按现有 Query 缓存复用；
- 失败时显示“无法加载详情”和“重试”；
- 错误只占用检查器内容区，不覆盖或禁用画布；
- 不显示原始服务器响应、Zod 错误或堆栈。

## 9. 节点拖动与临时位置

所有节点可拖动，包括中心节点。

- 鼠标移动超过约 `4px` 才识别为拖动；
- 未达到阈值时按普通点击选择处理；
- 拖动不改变当前选择，也不改变检查器开关；
- 拖动结束后 Cytoscape 保持节点的新坐标；
- 不显示固定图标或位置已保存提示；
- zoom、pan、选择变化和检查器开关不清除坐标；
- 取得新的图响应、切换中心、切换方向或重新布局时使用新的 ELK 坐标，自动清除旧位置；
- P1-08 不实现手工解除固定和坐标持久化。

P1-07 可见图提交时的 `lock()` 和 `autoungrabify` 配置在 P1-08 调整为允许节点抓取。后台无头 Cytoscape 仍只负责生成初始 ELK 坐标。

## 10. 前端架构

采用“Runtime 上报交互，页面保存状态，检查器独立查询”的方案。

### 10.1 组件职责

- `CausalGraphPage`：保存 `selection` 和 `inspectorOpen`，处理图响应更换、URL 更新和清理时机；
- `CausalGraphCanvas`：管理画布 DOM 焦点、快捷键、可访问播报和 Runtime 生命周期；
- `CausalGraphInspector`：检查器外壳、关闭、空选择、内容滚动；
- `EventInspectorContent`：事件详情查询、错误和“设为中心事件”；
- `RelationInspectorContent`：关系详情查询、错误和案例链接；
- `createGraphRuntime`：封装 Cytoscape 实例、事件监听、样式类、resize、ensure-visible 和拖动；
- `graphNavigation`：无框架的空间方向候选计算；
- `graphStyles`：集中维护 P1-07 基础样式和 P1-08 当前/邻接样式。

### 10.2 Runtime 边界

`GraphRuntime` 增加窄接口，页面和检查器仍不接触原始 Cytoscape 实例：

```ts
type GraphElementSelection =
  | { type: 'node'; id: string }
  | { type: 'relation'; id: string };

interface GraphInteractionCallbacks {
  onSelect(selection: GraphElementSelection): void;
  onClearSelection(): void;
}

interface GraphRuntime {
  // P1-07 layout and viewport methods remain
  setSelection(selection: GraphElementSelection | null): void;
  navigate(
    selection: GraphElementSelection | null,
    direction: 'up' | 'down' | 'left' | 'right',
  ): GraphElementSelection | null;
  resize(): void;
  ensureVisible(selection: GraphElementSelection, padding: number): void;
  subscribeInteractions(callbacks: GraphInteractionCallbacks): () => void;
}
```

方向导航可直接读取 Runtime 提供的节点坐标和关系端点快照，但候选排序交给纯函数，便于不依赖 Canvas 的单元测试。

### 10.3 状态与数据流

```text
鼠标点击 / 方向键
        ↓
GraphRuntime 解析目标
        ↓
CausalGraphPage 更新 selection
        ↓
Canvas 应用 current/context 样式
        ↓ inspectorOpen=true 时
Inspector 按类型调用现有详情 API
```

选中状态不进入 Context、URL 或持久化存储。详情响应只保存在 TanStack Query 缓存中。

## 12. 错误与边界情况

- 已选择元素在新图响应中不存在：清除选择并关闭检查器；
- 详情请求返回 404：显示“该节点不存在”或“该关系不存在”并提供关闭操作；
- 详情请求失败：保留当前选择和高亮，检查器可重试；
- 关系案例为零：正常显示空案例状态；
- 当前节点没有符合按键方向的相邻关系：保持原选择；
- 关系两端在视觉上与按键方向都不匹配：保持原选择；
- 多条关系连接相同节点：使用各自中点和 ID 保证稳定选择；
- 反向关系：按真实原因端、结果端和实际画面坐标导航，不根据数组方向猜测；
- 自环在数据库中已禁止，P1-08 不增加自环导航逻辑；
- 画布失去焦点后方向键和空格不触发图操作；
- 检查器加载期间仍可缩放、平移、拖动和改变选择。

## 14. 人工复核

自动化门禁通过后检查：

1. 图生成后没有默认选择；
2. 节点选择的一跳高亮范围正确；
3. 关系选择只高亮关系和两个端点；
4. 其他元素没有降低透明度；
5. 没有悬浮高亮或 Tooltip；

## 16. 方案评估

已比较：

1. Runtime 上报交互、页面保存状态、检查器独立查询；
2. 把所有选择、详情和拖动逻辑写入 `CausalGraphCanvas`；
3. 新增全局 Graph Context 和 reducer。

选择方案 1。它让 Cytoscape 命令、React 状态和业务详情保持隔离，同时不引入当前规模不需要的全局状态。

详情布局已比较右侧检查器、元素旁浮层和底部抽屉。选择固定右侧检查器，因为它不遮挡当前元素、可以稳定展示 5 条案例，并在桌面端提供一致的阅读位置。
